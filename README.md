# Игра в жанре «Tower Defence» с применением ИИ для динамической корректировки сложности

Репозиторий содержит материалы выпускной квалификационной работы (ВКР), посвященной разработке игры в жанре Tower Defense с интеграцией искусственного интеллекта, который динамически подстраивает сложность под стиль игры пользователя.

## Документация проекта

Все основные сопроводительные материалы и отчетность находятся в директории `docs`:

* 📄 **[Пояснительная записка (ПЗ)](docs/ПЗ.pdf)** — подробное теоретическое описание, архитектура проекта, реализация алгоритмов ИИ и результаты тестирования.
* 📊 **[Презентация проекта](docs/Презентация.pptx)** — слайды для защиты выпускной квалификационной работы.
